# WebMarks

- Project to store Web Bookmarks and manage them
- Practice in Next.js, Prisma and Authentication
- In project used:
  - Next.js
  - Prisma (PostgreSQL)
  - jose (session)
  - React (Context without State Managements)
  - React Hook Form
  - Zod
  - Typescript
  - ShadCN UI (Tailwind)
  - Husky + nano-staged
  - FSD
