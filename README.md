# WebMarks

- Project to store Web Bookmarks and manage them

## Features

- Instant Navigation: navigate through app with instant SPA experience
- ViewTransition: animations with browser API
- Cache Components: get cached data and invalidate data on mutations by tag
- Partial Prefetching: prefetches one shared App Shell per route. Links with prefetch={true} also resolve dynamic params and searchParams (You can turn this off by remove prefetch from Links to reduce server, network and DB load)
- Auth: auth in app and use your data between different devices
- DB: store user data in PostgreSQL
- Server Actions: safe mutations with auth checking and validation form data by Zod on server with special action id generated by Next.js

## Getting Started

1. Set up `SESSION_SECRET` in **.env.local** (generate random secret in terminal `openssl rand -base64 32`)
2. Check `DATABASE_URL` in **.env** for correct username, password, host and database name
3. Run commands (`pn prisma:seed` is optional)

```terminal
pn i
pn prisma:push
pn prisma:seed
pn prisma generate
pn dev
```

## Tests

### Projects

#### dom

- Extension: `*.test.{ts,tsx}`
- Runs in **happy-dom** environment
- Uses `fileParallelism: true`

#### node

- Extension: `*.node.test.{ts,tsx}`
- Runs in **node** environment
- Uses `fileParallelism: false`
- Up test DB in Docker to run tests

### Commands

- `pn test` - Up Docker test DB and runs tests in the both projects environments (dom and node). Watch for changes.
- `pn test:run` - Same as `pn test` but run the tests once without watch mode.
- `pn test:dom` - Runs **dom** project tests. Watch for changes.
- `pn test:node` - Up Docker test DB and runs **node** project tests. Watch for changes.
